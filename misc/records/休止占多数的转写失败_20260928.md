## 为什么它能在库里:闸门漏了一类

流水线有"**念白 `x` 占比异常**"的闸(`quarantine_highx.py`:x>=30% 且 >=10 个 x -> 移出),
也有一条"旋律 < 5 个音"的闸(`quarantine_short_scores.py`)—— 但这些谱是 **9 个音**, 从两条缝里都漏过去了,
而**休止 `0` 没有任何闸**。

它们对检索不只是"没用", 还可能**有害**:9 个音的片段极短、极易与别的歌撞上(检索里
`L=7 音 0 错` 时并列组平均就有 39.6 首), 等于往索引里塞噪声。

## 形状实测:阈值选在了对的地方

```
语料 8943 首(隔离前)的 "休止/延长占比" 分布:
   0.0~0.3   8365 首 (93%)      0.3~0.5    519 首
   0.5~0.6     17 首   <- n_notes 都在 113~188, 休止是**正常的**(长音多), 不是失败
   0.6~0.7     13 首   <- n_notes 16~117, 混杂
   0.7~1.0     17 首   <- ★ 全是"9 个音/几十个延长"的失败谱
```

**`>=0.70` 且 `token>=40`** 这条线正好把"失败谱"和"正常但长音多的谱"分开(隔离后 0.7~1.0 这一档为 0 首)。
17 首里 **10 首是今天导入的**, 7 首是原来就有的。
