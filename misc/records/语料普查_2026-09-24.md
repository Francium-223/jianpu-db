## 几个容易被问到的数

* **7,321 首 / 1,301,430 音高音 / 336,414 小节**（口径：音高音不含休止；`n_notes` 字段含休止，是 1,429,986）
* **小节是"推算"的**：语料 token 不写小节线，`recover_bars` 按拍数推（全语料只有 3 首含 `|`）→ 网页上的小节线是近似值
* **`scores/` 里有 7,820 个 txt**，其中 **499 个不进数据集**：273 个 `status=midi`（多轨转储，合计 474 万音）+ 225 个无 status 的空壳 + 1 个空谱（详见 `待整理的499是什么_2026-09-24.md`）
* **隔离区**（只移不删）：`jianpu-db/scores-suspect/` 里 junk / dup-identical / 短谱，各有 README
* **多版本**：按曲名归组有 248 组 ≥2 个版本，但其中 **169 组版本间毫不相似**（同名不同曲，详见 `同名不同曲_2026-09-24.md`）
