# 拍号/小节能不能从语料内部验证？——**基本不能**（2026-09-24 09:45–10:05）

> 这一节是个**否定结果**，写下来是为了以后别重复走这条路，并把顺带发现的 3 个小异常记上。

## 1. 试过的两条路，都不成立

| 想法 | 为什么不行 |
|---|---|
| 拿**总拍数**比声明拍号，余数≠0 就是"拍号写错" | **不可辨识**：只要有**弱起**（pickup），余数天然不为 0 —— 任何余数都能被"弱起 p 拍"解释掉。实测 90.2% 的歌有余数（余数多为 0.25/0.38/0.12 这种分数拍），完全符合"弱起 + 末小节不完整"的正常写法 |
| 拿**显式小节线**逐小节验拍数 | 没有可验对象：全语料 **7,321 首里只有 3 首**正文含 `|`（0.04%），而且那 3 首的"小节"是 28/84/116 拍那种东西 |

**根因**：语料的 token **不写小节线**，小节是 `recover_bars` 按拍数**推算**的（所以网页上显示的小节线是**近似值**，锦囊里早写明过）。要判拍号/小节对不对，**只能对着原扫描件看**（图片在 `../images-prep/` 与 `jianpu2/images-prep/`）。

工具已按这个结论降级：`jianpu2/tools/audit_meter.py` 现在只出**描述统计**（总拍数/拍号/余数分布 + 列出那 3 个带 `|` 的文件），并在 docstring 里写明"**它不下'拍号错了'的结论**"。
