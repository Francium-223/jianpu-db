# 曲名病灶（二）：括号不配对 208 首 + `source_pages.json` 的 `via` 证据审计（2026-09-25）

接着同一天那 40 首"尾部悬挂分隔符"往下挖，又挖出两类。

## 一、括号不配对的曲名：208 首

```
一切刚刚好（李健          世界末日（             The Sound of Silence（
Danny Boy（小野丽莎       OVER THE RAINBOW）     《 郴 州 行 》 （张 也
亲爱的你啊（三声部合唱     世纪中国梦（合唱        东江之歌 （
```

成因与"悬挂分隔符"是**同一件事**：早前某版解析把歌手/注解用括号拼进曲名，后来不拼了，
于是留下半个括号（或者只剩一个闭括号）。

**与那 40 首的关键差别**：这 208 首**几乎没有 `artist=` 字段** —— 例子里 `Danny Boy（小野丽莎`、
`一切刚刚好（李健` 的 artist 都是空的。所以没法像那 40 首那样"用 artist 自证"，
只能靠曲名自身的形状判断。**因此这批只出提案，没有落地**（落地要人过一遍）。

新增 `tools/propose_title_cleanup.py`（只写 TSV，绝不动语料）：

* 判据是**括号配对扫描**（栈），不是正则猜 —— 正则很容易把配对良好的
  `Take Me To Your Heart（吻别）` 也当成"多余闭括号"砍掉（我第一版就写错成那样，实测发现）；
* `未闭合开括号` 199 条 / `多余闭括号` 9 条；
* 置信度：截下来的那段**短（≤12 字）且不含标点**（多半是歌手/注解），或开括号后面**什么都没有**
  （`世界末日（`），标 `accepted=1`；否则标 0 交人看。
  ——实质 201 条高置信、7 条需要人判（如 `凤凰于飞（连续剧《后宫甄嬛传》片尾曲`）。

产物：`_analysis/title_bracket_proposal.tsv`（`file / current_title / proposed_title / kind / accepted`）。

**为什么没直接改**：那 40 首能自动改，是因为 `artist=` 能自证；这 208 首不能。
而且里面还有真歧义：`【日】Lemon电视剧_非自然死亡_主题曲_ドラマ「アンナチュラ` 是被截断的正题
（原题应到「アンナチュラル」），砍成 `…_ドラマ` 是错的 —— 这类标了 0。

## 二、`source_pages.json` 的 `via` 证据是个循环论证（**没改数据**）

7,132 条里 `via:title` 7,008 / `via:id` 124。查下来：**`via:id` 里有 100 条不是真证据**。

原因在 `candidates()`：jianpucn / jianpujia 的候选 URL 是**按 id 拼**出来的
（`/pu/{sid[:2]}/{sid}.htm`），所以"URL 路径里有 id"是**循环论证** —— 只证明了
"我们自己拼的 URL 返回过 200"。只有 qupu123 的 URL 是 `find_qupu123()` **站内搜索**搜出来的，
那里的 id 才算独立证据。

给 `verify_source_urls.py::check()` 加了 `id_is_evidence` 开关（只对 qupu123 为真），
然后把那 100 条**单独重核**（写到临时文件，没动 `source_pages.json`）：

```
待办 100 个 source; 写出 (39 条)
   jianpucn:title 15   jianpujia:title 24      <- 39 条其实标题对得上(真证据)
   jianpucn:miss  49   jianpujia:miss  12      <- 61 条没核过
```

再把那 61 条按"为什么没过"拆开（逐条抓页面看 HTTP 码与页面标题）：

| 原因 | 条数 | 说明 |
|---|---|---|
| 我方标题太短（<2 字），标题核对根本跑不了 | **39** | `家`/`谁`/`烧`/`《归》`。核对逻辑有 `len(nw)>=2` 的保护，短标题一律跳过 |
| 页面 200 但标题对不上 | **18** | 多数是"我们这边的标题是被清理/截断过的变体" |
| 其实对得上（上次是偶发失败） | 4 | |
| 合计 | 61 | |

那 18 条里就藏着上面那批括号病灶，例如：

```
我方 难忘的爱人】彩谱】        页面 难忘的爱人（台语）】彩谱】 邓丽君
我方 好好（尤克里里            页面 好好(想把你写成一首歌)（尤克里里弹唱谱） 五月天
我方 人生无悔 电视连续剧片尾主题歌   页面 人生无悔 电视连续剧(风雨丽人)片尾主题歌
```

**结论**：`via:id` 这个标签对 jianpucn/jianpujia 没有意义（循环论证），
但也不该直接删条目 —— 39 条已重新确认为真、39 条只是被短标题规则挡住。
要彻底修得：① 给短标题一条**更严但可用**的判据（如"页面标题以我们的曲名开头"），
② 结果先写独立文件再与现表 diff。已记入待办，**本轮没改 `source_pages.json`**。

## 三、复现

```bash
cd jianpu2
python3 tools/propose_title_cleanup.py            # 208 条提案(只写 TSV)
# 100 条 via:id 的重核:
python3 - <<'EOF'
import json, io
sp=json.load(open('../jianpu-db/source_pages.json',encoding='utf-8'))
sus={k for k,v in sp.items() if isinstance(v,dict) and v.get('via')=='id'
     and k.split('-')[0] in ('jianpucn','jianpujia')}
out=io.open('/tmp/suspect_data.jsonl','w',encoding='utf-8')
for line in io.open('../jianpu-db/data.jsonl',encoding='utf-8'):
    r=json.loads(line); s=r.get('source') or []
    s=s[0] if isinstance(s,list) and s else s
    if s in sus: out.write(line)
EOF
python3 tools/verify_source_urls.py --data /tmp/suspect_data.jsonl \
        --out /tmp/suspect_out.json --sites jianpucn,jianpujia --workers 4 --interval 0.5
```

## 四、后续（同夜）：用**页面标题佐证**，把其中 92 首落地了

第一版只出提案，是因为这 208 首**没有 `artist=` 可自证**。但还有一条独立证据没用上：
**`source_pages.json` 里记着每首的原谱页标题**。拿它给提案做佐证（归一化后页面标题**以新曲名开头**），
结果：

```
括号不配对的曲名: 208 首
出提案: 208 条
   页面标题能佐证: 103 条
   佐证 + 形状干净 -> accepted=1: 92 条
   未闭合开括号   199 条 (accepted=1 91)
   多余闭括号       2 条 (accepted=1  1)
   多余闭括号(多个) 7 条 (accepted=1  0)
```

三个判据收紧的地方（都是实测踩出来的）：

1. **佐证必须"以新曲名开头"，不能用"包含"**。第一版写的是"包含"，于是
   `【日】Lemon电视剧_非自然死亡_主题曲_ドラマ「アンナチュラ` 砍成 `…_ドラマ` 也算通过 ——
   页面标题确实**包含**它，但那是把日本原题截断了，不是我们要的。
2. **`多余闭括号` 不能只去一个**。`难忘的爱人】彩谱】` 只去掉第一个 `】` 会得到
   `难忘的爱人彩谱】` 这种半成品 —— 看着像又一条错题。现在若去掉后**仍然不配对**，
   就整条标 `多余闭括号(多个)` + `accepted=0`，交人看（7 条）。
3. **落地前再验一次形状**：`accepted=1` 要求"佐证 + 形状干净"两者都满足。

**落地 92 首**（`propose_title_cleanup.py --apply`，复用 `refine_titles_from_pages` 的改名机器，
含冲突规则与首行 `%<本文件名>` 同步）。终检与那 40 首同一套：

```
改名 92 首: 除首行/title/todo 外**逐字节相同** = 92 / 92, 异常 0
全库首行 %<名> 与文件名不一致 = 0
data.jsonl 未手改(等 CI 重新生成)
```

剩下 116 首（103-92 之外的、以及没有页面记录的）仍是提案状态，`accepted` 列留给人过。

顺带说明：这批里 `晚风（.txt` 的页面标题是 `晚风 （简谱）_乐记简谱个人制谱园地_中国曲谱网`，
所以正确曲名就是 **晚风**（`（简谱）` 是描述）—— 它**不是**金曲缺口里的《晚风心里吹》，
两首不同的歌。这种"用页面标题把话钉死"正是上面第 1 条判据的价值。
