## 一个值得记下的检查细节

我第一版体检用的是**像素面积**阈值（`< 100x100`），于是 `2598x42 = 10.9 万像素` 这种
**细条图被漏掉**了 ✗；新工具改成看**短边**（`min(w,h) < 100` 就算细条）→ 立刻揪出 3 张。
**教训**：验"图能不能用"要看**形状**，不能只看总面积。

## 怎么用

```bash
python3 jianpu2/tools/check_images.py --queue                 # 验转写队列里的图
python3 jianpu2/tools/check_images.py ../images-prep/jianpucn-pop   # 验任意批次
python3 jianpu2/tools/check_images.py <目录> --min-px 200      # 换短边阈值
```
