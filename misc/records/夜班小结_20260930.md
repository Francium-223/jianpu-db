## 二·补、**我自己捅的一个错并修掉**（照实记）

上一版"织体页"判据是**逐页丢 >300 音**，跑进回锅批次后实测 **13 份真歌被截断**（丢 18 页）：

|---|---|---|---|
| 圣诞结 | 321 / 397 / 417 / 112 | 3 | 416 → **112** 音 |
| 旅行 | 170 / 187 / 371 / 507 | 2 | 1580 → **357** 音 |
| 摩天大楼 | 371 / 508 / 180 | 2 | 1059 → **180** 音 |

| …共 13 份 | 这些谱**每页中位只有 285 音**（旋律谱 p90=265） | 18 页 | |

⇒ 把**正常流行歌最密的那几页**当织体丢了。正应了我自己先写下的那句"截断旋律比留着噪声更糟"。
改成**按整份谱判**：单页 >600 音才丢那一页（只兜极端），整份每页中位 >400 才整份跳过。
400 这条线也是实测的：13 份真歌的每页中位最高 **397**，明确织体是 `BEYOND_THE_TIME钢琴简谱`
中位 **438**、`贝斯谱_邓丽君3` 中位 **620** → 正好分成"13 留 / 2 跳"，**一页都不截断**（离线用
真实页音数逐个验过）。被截断的 13 份已排进补转（等整条链跑完再跑，避免两个模型抢显存）。

**教训**：判据上线前要拿"已知是好的样本"回归一遍 —— 这次只盯着"坏样本能不能挡掉"，
没验"好样本会不会被误伤"，于是把真歌截断了。
