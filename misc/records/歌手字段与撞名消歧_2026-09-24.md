# 歌手独立成字段 + 撞名文件消歧（2026-09-24 14:30）

用户口径：**歌手不该只混在 `usertag` 里** —— 要 `artist=歌手名` 独立字段，并且**文件名消歧**
（通用曲名《海阔天空》《爱》《家》原来靠 `_2`/`_3` 这种无信息后缀区分 ✗）。

## 做了什么

**1. 字段链路打通（schema → 记录 → 网页 → HF）**

| 环节 | 改动 |
|---|---|
| `schema.py` | 注册 `artist`（多值；与 `分类/…` 标签分开） |
| `score.py:to_record` | 扁平记录带上 `artist`（以前下游问不到"这首谁唱的"） |
| `jianpu-web/tools/build_web_data.py`、`static/search.js` | 前端索引进 `artist` |
| `jianpu-web/static/app.js` | 卡片在「曲名」下面新增 **「歌手」** 一行 |
| `jianpu-db/export_hf.py` | HF 导出的 COLS 与每行都带 `artist` |
| `jianpu-db/linkurl.py` | 新增 `add_field()` —— 写进曲谱**仍然只有一处实现**，且值不许含换行 |

**2. 灌数据（证据来自原谱站页面，不靠曲名猜）**

* `artist=` 写入 **1,293 首**；歌手来自 `harvest_artists.py` 按 `source` 缓存的**页面标题**，
  所以按 source 匹配 —— **以后文件改名也不受影响** ✓
* 页面上抽出来的"歌手"混着版本描述（实测 `双吉他版`、`吉他 — Beyond`、`电子琴伴奏配器 邓丽君`），
  所以加了过滤：含版本/乐器/谱类关键词的不算人名；若整串里含**已知歌手名**就取那一段
  （`怀旧经典 邓丽君` → `邓丽君`）。这类噪音被挡掉 **14** 条。
* 大小写取"多数派"写法（避免 `Beyond`/`BEYOND` 并存）。

**3. 撞名文件消歧**

* 183 个"同名不同曲"组里，**30 个成员文件**改成了 `曲名（歌手）.txt`：
  `丑八怪.txt` → `丑八怪（薛之谦）.txt`、`蝶恋花_答李淑一` 两个版本分别成 `（李谷一）`/`（殷秀梅）` ✓
* 同一组里两首都归到同一歌手（多半是同一首的重复转写）→ 加 `_2/_3` 保证唯一
* **还有 171 组**的歌手信息不全，改不了 —— 需要人补（补完再跑一次 `set_artists.py --rename` 即可）

工具：`python3 jianpu2/tools/set_artists.py [--apply] [--rename]`（默认 dry，先看计划）。

## 顺带把"语料安全网"做得更有用

`corpus_fingerprint.py` 原来会把**有意改名**报成"消失 N 份 + 有问题"✗（这次就误报了一次）。现在：

* 按**正文哈希**认改名 → 报"改名 30 份"并列出 `旧名 → 新名` ✓
* 把**新增元数据键**（如 `artist=`）与**键丢失/改名**（真正的写坏，如 `todo=` 变 `dtodo=`）**分开报** ✓

本次核对的结论因此变成：**没有异常** ✓（改名 30 / 新增键 1,263 / 键丢失 0 / 正文变化 0）。
