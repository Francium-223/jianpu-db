# 同名异源交叉验证: 能做"互相印证", 做不出"错误率"

日期: 2026-09-28
工具: `tools/audit_title_agreement.py`(只读)
产物: `_analysis/同名异源一致性.tsv`

## 动机

之前只肉眼对图看了 4 首, 说不出转写错误率。而语料里不少歌有**多个来源**各转了一份 ——
它们是互相**独立**的转写, 两份旋律大面积对不上就说明至少一份错了。这条路不需要 GPU、
不需要重跑模型, 本来是想拿它量错误率的。

口径: 音高序列用 `lookup.pitch_and_oct`(与检索同一口径, 丢休止/念白、丢八度);
另算**最长公共连续段(LCS 块)** —— 同一首歌的两份独立转写总该有一大段逐音相同;
再补一列**整体移调后**的 LCS(唱名整体移 1~6 级后取最大), 用来把"同一首歌按不同调记"和
"根本是两首歌"分开。

## 实测(8926 首语料)

| 量 | 数 |
|---|---|
| 同名组 | 7,563 |
| 其中**含至少两个不同源**的组 | 263 |
| 跨源配对 | 466 |
| 整串相似度 =1.000 | 19 (4.1%) |
| ≥0.95 | 43 (9.2%) |
| 0.80~0.95 | 51 (10.9%) |
| 0.60~0.80 | 107 (23.0%) |
| <0.60 | 246 (52.8%) |

LCS 块分布: `≥48` 110 对 (23.6%) / `24~47` 111 (23.8%) / `12~23` 134 (28.8%) / `<12` 111 (23.8%)。

**移调那一步的结果是关键**: LCS<24 的 245 对里, 按"整体移调"重比之后 LCS 升到 ≥24 的有
**0 对**(多数只从 5 涨到 6、7 涨到 10)。也就是说"同曲异调"**不是**这里的解释 ——
对不上就是对不上, 不是调号写法差异。

## 结论(别过度解读)

* **能说的**: 466 对里有 **221 对(47.4%)** 存在 ≥24 音的逐音相同长段 —— 这是两份独立转写
  **互相印证**的正向证据。这 221 对可以放心当"转写正确"用。
* **不能说的**: 剩下 245 对**不能**当成"52.8% 转写错误"。同名不同歌是主要混淆源
  (`喜欢你` 有 Beyond 版也有别人的同名歌, `难忘的一天` 邓丽君与许巍是两首完全不同的歌,
  `两只老虎` 两份 264 音 / 329 音); 其次是不同段落/编配(`一路生花（二部合唱谱）`,
  `致青春钢琴`)。
* 换句话说: **这条路给不出错误率**, 它只能给"互相印证的下界"。要真的量错误率, 得用
  手写 GT 那一套(`train-work/gt/` 8 首手抄谱 + `tools/gt_transcribe_eval.py`, 对图重转再比),
  它没有配对歧义(之前去语料里按文件名找"同一首歌"配错版本, 算出过 1.6% 的假数字)。
  今晚 GPU 被转写批次占着, 等空出来再跑。

## 顺带发现

`两只老虎` 两份分别 264 / 329 音, 一首八小节的儿歌不该有几百个音 —— 这两份**都**可疑
(可能是把整本谱或联唱一起转了)。这类"长度离谱"的样本可以当独立的质量信号用, 但没做。
