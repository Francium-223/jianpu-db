## 放 token 的两个位置（任选其一）

```bash
mkdir -p ~/.config/jianpu
printf '%s' 'ghp_xxx或github_pat_xxx' > ~/.config/jianpu/github_token   # GitHub
printf '%s' 'hf_xxx'                    > ~/.config/jianpu/hf_token       # HuggingFace
chmod 600 ~/.config/jianpu/*
```

或者放在工作区里（同样被 `.gitignore` 覆盖，不会被提交）：`_analysis/.github_token`、`_analysis/.hf_token`。

## 有 token 之后一条命令搞定

```bash
bash _analysis/推送.sh          # 会自己检查/创建缺失的远端仓库, 然后推三个库
HF_TOKEN=hf_xxx bash _analysis/上传HF.sh     # 或放好 hf_token 文件后直接跑
```
