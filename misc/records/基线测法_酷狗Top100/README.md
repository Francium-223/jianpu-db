# 基线测法：数字旋律猜歌（酷狗华流 Top100）

目的：给"有这套数据集/技能 vs 没有（通用大模型）"一个**同一套题、可复核**的对比数字。

## 题目从哪来

`eval_golden.py --list train-work/eval_set_kugou_hualiu_2025.tsv --lens 15 --errs 0 --per-song 1 --dump-queries`
—— 和本项目自测**完全同一批查询**：每首取开头 **15 个音**、**零错音**、每首 1 题。
98 首榜单里 **61 首**在语料内可定位（另 37 首库里没有 → 对两边都是"答不出"，不计入分母）。

- `题目_盲测.txt`：61 道题（**只有数字，没有答案**），直接整段贴给 ChatGPT / Claude / Gemini。
- `答案.tsv`：序号 ↔ 查询 ↔ 期望歌名（评分用，别提前给模型）。

## 怎么测才站得住

1. **同题**：用 `题目_盲测.txt` 原文，61 题一次贴过去（或分批，记录对应序号）。
2. **禁止工具**：明确写"不要联网、不要搜索"（否则它可能去搜谱站，那就不是"模型自身能力"了）。
3. **一次作答**：不要追问、不要给提示、不要重试挑最好的那次。
4. **评分**：只要给对**同一首歌**就算对（别名/译名/带演唱会版本后缀都算，参考 `答案.tsv` 的 `应答` 列）。
5. 记录：模型名 + 版本 + 日期 + 对/错条数。
