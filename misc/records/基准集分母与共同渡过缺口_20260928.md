## 缺的那一首:`共同渡过`

它不是"匹配不上",而是**整条流水线里都没有**:

```
jianpu-db/scores      无
batch-out             无
batch-out-dup         无
jianpu-db-out/scores  无
```

→ **这是一个覆盖缺口**(没抓到 / 没转写),不是索引或匹配的问题。属于"下一步该补的歌"。
