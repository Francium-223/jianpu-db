# 来源兜底、以及 7 个 hot-crawl 目录的图没挂上 —— 2026-09-28

两份都是"检查器报了红 / 看着像缺口",查到最后发现**一处是我的检查器错、一处是真缺口但很小**。

---

## ① 那 4 个"形状不对"的 `source`,是**设计好的兜底**,不是缺陷

`check_corpus_invariants.py` 一直红着唯一一类:`source 形状不对` —— 4 首:

| 谱 | source |
|---|---|
| 不潮不用花钱.txt | `unknown` |
| 相思遥.txt | `unknown` |
| 英雄.txt | `21qupu` |
| 英雄_2.txt | `qpcxw` |

追到 `tools/to_jianpu_db.py:166 source_of()`,它的兜底分支(第 268-287 行)写得明明白白:

```
# 兜底: 少数目录名没有 `__站点-id`(手工抓的 hot-crawl), 但**不能因此就不写来源** ——
# 之前这样漏出 4 份无 source= 的谱(实测 `不潮不用花钱`/`相思遥`/`英雄_21qupu`/`英雄_qpcxw`)。
# 顺序: ①目录里记的原页 URL(grab_sheet 现在会写 _source.txt) ②名字里认得出的站点 ③老实写 unknown。
```

而且那三级兜底的第②级就是一张站点 token 表:`("21qupu", "qpcxw", "qinyipu", "gita")` ——
`英雄_21qupu` / `英雄_qpcxw` 正是这么来的(目录名里带得出站名, 但没有页面 id)。

**所以该改的是检查器**: 把 `unknown` 与站点 token 归为"良性:兜底来源"(只报数),
其余形状仍然红。改完:

```
检查 7318 首
良性记号(不报警, 只报数):
   连音线 ~ (良性)                     191 个
   source=unknown(兜底: 出处确实没记)       2 个
   source=<站点 token>(兜底: 只有站名没有页面 id)     2 个
   正文里的调号 (良性)                      1 个
结构不变量全部通过（7318 首）          exit 0
```

检查器里那张 token 表与 `to_jianpu_db.py` 里的**必须同步**(已在注释里写明出处)。

## ② 7 个 hot-crawl 目录的整页图没进图索引(真缺口, 但只有 19 页)

`build_image_index.py` 的钥匙是目录名里的 `__<source>`(`if "__" not in base: skipped_nokey += 1`),
而手工抓的 `hot-crawl` 那批目录名**只有标题**(或标题+单下划线站点)。

用工具自己的 `scan()` 量(没有另写一套口径):

```
dirs=20050  files=38685  sources=17167  pages=22719  skipped_nokey=8
```

也就是 **20,050 个目录里只有 7~8 个**被跳过。逐个列出来:

| 目录 | 整页图 | 语料里对应的 source | 能不能安全追回 |
|---|---|---|---|
| `hot-crawl/不潮不用花钱` | 3 | `unknown`(另有 jianpujia 版) | ✗ 名字里没有来源 |
| `hot-crawl/千千阙歌` | 7 | `qupu123-260965`(图另有出处) | ✗ 同上 |
| `hot-crawl/烟火里的尘埃` | 1 | `jianpucn-275914`(图另有出处) | ✗ 同上 |
| `hot-crawl/烟火里的尘埃_gita` | 4 | (语料里没有 gita 这条) | ✗ |
| `hot-crawl/相思遥` | 1 | `unknown` | ✗ |
| `hot-crawl/英雄_21qupu` | 1 | **`21qupu`** ✓ | ✓ 来源对得上 |
| `hot-crawl/英雄_qpcxw` | 2 | **`qpcxw`** ✓ | ✓ 来源对得上 |

**没改图索引**,理由:

* 能安全追回的只有 `英雄` 那两条(3 页)—— 而"改目录名成 `英雄__21qupu`"会牵动**转写产物的命名**
  (`to_jianpu_db` 按目录名推标题与文件名), 为 3 页去动这条链不划算;
* 其余 5 个目录名里**根本没有可用来源**, 只能按标题猜 —— 而 `英雄`/`英雄_2` 就是"同名不同曲"的活例子,
  按标题挂图会**错配**(项目口径: 错配比没有更糟);
* 全工具链的规范是 `__`(46 处 `split("__")`), 只有这 7 个手工目录是例外。

**记为已知缺口**: 19 页里有 3 页(`英雄` 两版)是"来源已知但没挂上", 其余 16 页是"目录名里没有来源"。
将来若要让 `hot-crawl` 那批也进索引, 正确做法是**抓取时就把目录名写成 `<标题>__<source>`**,
而不是在图索引里加"按标题猜"的分支。
