# 人工补标签这条路**曾经是断的** —— 修复记录（2026-09-24 05:55–06:20）

> 这条链路是"给 941 首无标签的歌补标签"的唯一人工入口：
> `--emit-template` 导出待补清单 → 人填 `human_tag` 列 → `--from-tsv` 写回曲谱。
> 它**两个命令都崩**，而且崩了很久没人发现。

## 1. 症状与根因

```
$ python3 tools/propose_tags.py --from-tsv _analysis/tag_todo.tsv
NameError: name 'apply_tsv' is not defined
$ python3 tools/propose_tags.py --emit-template
NameError: name 'emit_template' is not defined
```

根因：上一次重构 `336a2a9「propose_tags.add_tag 改为委托 jianpu-db/linkurl.add_usertag(口径只有一份)」
把 `add_tag` 换成了委托调用，但**顺手把 `apply_tsv` 与 `emit_template` 一起删了，而 `main()` 里的调用还在**。
（这是我的锅：那次重构是我做的，而当时的"自检"只跑了 `--help`。）

**为什么没人发现**：`check_tools.sh` 只跑每个工具的 `--help`，而 `--help` 在 argparse 就退出了，
**永远走不到 `main()` 的调用行**。这类 bug 只有真跑一遍才会暴露。

## 6. 顺带加固：标题改名这条写盘路径（同一个坑的另一半）

`refine_titles_from_pages.py --apply` 是"138 条曲名改名"的落地命令，也要做同样的检查：

* **读了一遍代码**：它是拿 `re.sub(r"(?m)^title=.*$", "title="+new, text)` 直接替换的，
  而 `new` 来自**网页标题**（不可信输入）—— 如果标题里带换行，就会往曲谱里**注入额外元数据行**
  （与标签那个坑同一类）。现有 275 条提案实测干净，但**来源是网页，必须在写入前兜住**。
* **修法**：新增 `clean_title()`（去 `\r\n\t`/控制字符、合并空白），在**生成提案时**和**落盘前**
  各清一遍；替换改用 `lambda m: "title=" + new` —— 这样 `new` 里的 `\1`/`\g<…>` 也不会被
  当成正则替换引用（原来的写法有这个隐患）。
* **隔离实测**（用真缓存、只动 /tmp 副本）：`title=牧羊姑娘1=F4_4_深情悠扬地` → `title=牧羊姑娘`，
  文件名同时改为 `牧羊姑娘.txt`，`todo=refine the filename` 被清掉；**真语料 0 变化** ✓。
* `check_tools.sh` 再补一条功能自测：隔离副本里跑 `--offline`，必须正常出提案（275 条）。

现在 `bash jianpu2/tools/check_tools.sh` 覆盖四层：**冒烟（--help）+ 静态（未定义名）+ 功能（标签写回、
